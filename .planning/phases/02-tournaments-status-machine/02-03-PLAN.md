<objective>
Public view vertical slice (TOUR-02, TOUR-03): anyone — including anonymous visitors — can open `/tournaments` to see all tournaments (newest first) each with a Russian status badge and a clear empty-state, and open `/tournaments/[id]` to see a tournament's info (name, size, fixed single-elimination-pairs format, date/location when set), its status badge, and a registered-pairs count `0/size` with a placeholder pairs list that Phase 3 will fill. Purpose: This is the consumer/read side of the phase and the only anonymous-reachable surface. It turns persisted tournaments into the visible artifact (status badge + detail) that later phases extend into the live bracket.

Output: status-badge component, public list page, public detail page (with not-found + placeholder pairs).
</objective>
