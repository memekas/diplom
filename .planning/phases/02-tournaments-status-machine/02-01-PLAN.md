<objective>
Foundation slice for the tournaments phase: the `Tournament` Prisma model (with `setsPerMatch`/`gamesPerSet` so Phase 5 needs no migration), the validation schema (name required; size ∈ {4,8,16}; date/location optional), and the two domain services — `createTournament` (initializes status `registration`) and the single server-side status machine `transitionTournament` with DB-checked guards (TOUR-04). Purpose: Everything else in this phase (admin create, public list/detail) reads/writes through these services and validation. Establishing the model + service contracts first lets the Wave-2 create and view slices be built against a known interface rather than discovered.

Output: `Tournament` model + applied migration; `tournament` validation; `tournament` and `tournament-status` services with passing unit tests.
</objective>
