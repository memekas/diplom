# Requirements — Milestone v3.0 (UI Redesign · Court)

Визуальный рестайл уже построенного фронтенда (v2.0) под зафиксированный дизайн-язык **Court**.
Функциональность, данные и backend НЕ меняются — каждое требование описывает, что экран
выглядит и ведёт себя по дизайн-контракту (skill `sketch-findings-diplom` + `.planning/sketches/`).

## v3.0 Requirements

### UI — Design foundation

- [x] **UI-01**: Тема Court (токены цвета/типографики/формы + компонентный слой) реализована в Tailwind 4 (`globals.css` / `@theme`) и доступна всем экранам; вёрстка адаптивна через container-queries (реагирует на ширину контейнера, а не окна).

### UI — Auth & account

- [x] **UI-02**: Экраны входа и регистрации оформлены в Court (таб-карточка Вход/Регистрация); поля и состояния читаемы на десктопе и на телефоне (~375px).
- [ ] **UI-05**: Профиль показывает карточку игрока (имя, @ник, уровень, сторона) и форму редактирования реальных полей (Имя, Никнейм, Сторона, Телефон, Уровень, Дата рождения; Email — read-only логин) в Court.

### UI — Browse

- [ ] **UI-03**: Список турниров — плотный список на десктопе и карточка-на-строку на телефоне; фильтры свёрнуты в кнопку «Фильтры» с поповером (Статус/Формат/Уровень/Вид) + поиск; бейдж активных фильтров.
- [ ] **UI-04**: ЛК-дашборд показывает «Мои турниры» по секциям (Активные / Предстоящие / Завершённые) с ролью игрока (пара с… / одиночный) и CTA, в Court.

### UI — Tournament pages

- [ ] **UI-06**: Страница турнира — programme-вёрстка: hero (название + статус), регламент-мета, стартовый лист с посевом и подсветкой «ваша пара», прогресс набора, CTA участия, в Court.
- [ ] **UI-07**: Форма создания турнира (админ) оформлена в Court и меняет поля по формату (Олимпийская → сетка 4/8/16; Круговой → число участников; Американо/Мексикано → Тип=Одиночный и Подсчёт=Очки заблокированы, появляется «Число раундов»).
- [ ] **UI-08**: Сетка плей-офф в Court — колонки раундов, карточки матчей с полными именами и set-tally, счёт по геймам по наведению/тапу, без счёта финала, баннер чемпиона; карточки и соединительные линии корректно выровнены на 4/8/16.
- [ ] **UI-09**: Форматные страницы в Court — Круговой («Матчи» по раундам + «Турнирная таблица») и Американо/Мексикано («Текущие/Прошедшие игры» + «Рейтинг игроков»).

### UI — Responsive

- [x] **UI-10**: Все экраны корректно отображаются на телефоне (~375px) без поломок и непреднамеренного горизонтального скролла (намеренный скролл допускается только для сетки плей-офф и широких турнирных таблиц).

## Out of Scope

- Любые изменения функциональности, данных, схемы БД, серверных экшенов — только визуально-вёрсточный слой.
- Новые экраны/фичи, не существующие в v2.0.
- Подключение UI-библиотек/компонент-китов — остаёмся на Tailwind 4 + собственный компонентный слой.
- Анимационные/моушн-системы сверх того, что зафиксировано в скетчах.
