# Requirements: Padel Tournaments — Milestone v1.1

**Milestone:** v1.1 — Никнеймы и запись по нику
**Defined:** 2026-06-06

> Требования предыдущего milestone (v1.0) — см. `.planning/milestones/v1.0-REQUIREMENTS.md`.

## v1.1 Requirements

### Никнеймы (USER)

- [ ] **USER-01**: Игрок задаёт никнейм при регистрации (обязательное поле формы регистрации, рядом с email/паролем/именем).
- [ ] **USER-02**: Уникальность никнейма гарантирована на уровне БД (`@@unique`) и проверяется при регистрации — попытка занятого ника отклоняется с понятным сообщением об ошибке, аккаунт не создаётся.

### Запись по нику (REG)

- [ ] **REG-04**: При участии в турнире партнёр указывается вводом никнейма в текстовое поле; система находит пользователя точным lookup по нику. Несуществующий ник → понятная ошибка. Список пользователей не предлагается.

## Future Requirements (deferred)

- Поиск/автодополнение пользователей по нику (предложение списка) — пока не требуется (REG-04 ограничен точным вводом).
- Редактирование никнейма в профиле — вне scope v1.1 (ник задаётся только при регистрации).

## Out of Scope

- Регистр-независимый / нормализованный матчинг никнеймов — точное сравнение достаточно для диплома.
- Бэкфилл-стратегия для «реальных» пользователей — существующие seed-аккаунты (админ, тестовые юзеры) получают ники в seed-скрипте.
